# Season 5 Go / No-Go 判定（2026-11-16 実施）

## 結論: **Go**

Sepolia 実機で 1 ハンドが最後まで通り、操作ごとの待ち時間も予算内だった。インディアンポーカーで進める。

## 判定の根拠

- 1 手あたり約 12 秒。楽観的 UI（押した瞬間にチップを動かす）と手番タイマーで体感の待ちを隠せる範囲。
- 勝負から結果までの待ちは約 13 秒で、めくり演出に収まる。
- `confirmFunds` はハンド開始と並行して背景で実行する設計なので、プレイ中の待ちに加わらない。

## ボットの復号（タスク 7、使い捨ての試作）

`@zama-fhe/sdk` の Node 版（`node()` + `asyncLocalStorage`）を、ボット役のアカウントで Sepolia に対して実行した。

- **相手のカードの復号に成功**（約 4 秒）。権限（permit）の付与は即時。
- **自分のカードは拒否された**（「このアカウントには ACL の許可がない」）。ボット自身のカードはボットにも見えない。
- SDK の `dist` は 8.5 MB。Vercel の関数サイズ上限（非圧縮 250 MB）には余裕がある。
- **Node（bun）では動いた。Vercel の実行環境（`vercel dev` / 本番）では未検証。** 検証はタスク 15 で行う。動かない場合は、ロジックはそのままに、常駐の小さなプロセス（Fly.io / Railway など）で動かす。
